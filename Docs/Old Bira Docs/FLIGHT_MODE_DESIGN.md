# OLD BIRA’S FARM — FLIGHT MODE DESIGN DOCUMENT

# Objetivo da Modalidade

Flight Mode é a modalidade principal do jogo.

O foco é:
- controle preciso;
- domínio de momentum;
- otimização de trajetória;
- navegação espacial;
- execução sob pressão.

---

# Filosofia de Movimento

O voo é baseado em:
- aceleração;
- empuxo;
- gravidade;
- momentum residual;
- controle direcional.

O controle deve ser:
- previsível;
- responsivo;
- consistente;
- preciso.

---

# Filosofia de Combustível

Combustível representa eficiência de voo.

- Acelerar consome combustível.
- Momentum reduz necessidade de empuxo.
- Jogadores habilidosos conseguem minimizar reabastecimentos.
- Algumas fases podem ser concluídas sem reabastecer.

---

# Estrutura das Fases

As fases são:
- curtas;
- intensas;
- densas;
- focadas em habilidade.

Duração média:
- aproximadamente 1 minuto.

---

# Filosofia de Falha

Ao morrer:
- o jogador volta ao início da fase;
- o cronômetro continua;
- a run permanece ativa.

Morrer penaliza performance, não progresso.

---

# Tipos de Desafio

## Precision Navigation
- túneis
- portas
- janelas
- passagens apertadas

## Momentum Control
- elevadores
- hovering
- plataformas móveis

## Timing Challenges
- lasers contínuos
- portas temporizadas
- alçapões
- hazards móveis

## Route Optimization
- economia de combustível
- coleta eficiente
- trajetórias rápidas

## Pressure & Hazard
- abelhas
- espaços confinados
- pressão constante

---

# Sistema de Maçãs

As maçãs:
- são obrigatórias;
- ativam landing pads;
- podem abrir portas e passagens;
- mantêm o jogador em movimento.

---

# Sistema das Abelhas

As abelhas não perseguem o jogador diretamente.

Elas funcionam como hazards móveis previsíveis:
- seguindo waypoints;
- patrulhando áreas;
- permanecendo estacionárias;
- ou executando movimentos orbitais.

Seu objetivo é:
- aumentar pressão;
- testar timing;
- dificultar rotas;
- exigir leitura rápida.
