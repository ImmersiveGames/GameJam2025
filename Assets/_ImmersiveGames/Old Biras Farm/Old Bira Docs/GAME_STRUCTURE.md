# OLD BIRA’S FARM — GAME STRUCTURE DOCUMENT

# Estrutura Principal

```text
Game
 ├── Modalidades
 │     ├── Grupos de Fases
 │     │      ├── Fases
 │     │      └── Desafios
 │     └── Recompensas
 ├── Sistema de Progressão
 ├── Sistema de Rankings
 ├── Sistema de Medalhas
 ├── Sistema de Unlocks
 ├── Sistema de Runs
 └── Sistema de Perfil
```

---

# Estrutura de Progressão

```text
Completar Grupo de Fases
    ↓
Desbloquear Novo Animal
    ↓
Desbloquear Próximo Grupo
    ↓
Completar Modalidade
    ↓
Desbloquear Nova Modalidade
```

---

# Sistemas Principais

- Rankings globais e entre amigos
- Medalhas por performance
- Sistema de runs
- Sistema de save persistente
- Unlock de animais
- Unlock de modalidades
- Progressão baseada em habilidade
