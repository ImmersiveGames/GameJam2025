Primeiro: como a Activity encontra seu componente?

Antes de falar em Reset, Snapshot, Release ou Permission, o objeto precisa estar visível para a Activity.

Com Actor

Actor / PlayerActor ├── ActorCapabilitySurface └── SeuComponente

Use quando o comportamento pertence ao Actor.

Sem Actor

Objeto da cena ├── ActivityObject / Contributor / Marker └── SeuComponente

Use quando o comportamento pertence a um objeto comum da Activity.
