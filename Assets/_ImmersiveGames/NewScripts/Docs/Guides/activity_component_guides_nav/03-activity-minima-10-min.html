Objetivo do tutorial

Montar uma Activity mínima chamada activity_01, com uma cena de conteúdo, sem entrar ainda em todos os detalhes de reset/save. Esta é a menor receita útil para alguém validar o fluxo.

Sobre os prints: os quadros abaixo imitam o Inspector. Eles servem como referência visual de preenchimento. Substitua nomes de menu/asset pelo nome exato disponível no seu projeto se o item aparecer com label diferente.

Passo a passo

Crie a pasta de teste

Use uma pasta clara para não misturar assets de teste com assets finais.

Assets/_ImmersiveGames/NewScripts/Resources/SessionActivity/Tutorial

Crie o Content Profile

Ele diz qual cena de gameplay será carregada pela Activity.

Crie o ActivityAsset

Ele declara o id da Activity e aponta para o Content Profile.

Crie ou atualize o ActivityCatalogAsset

Coloque activity_01 na lista de Activities da rota.

Rode o smoke mínimo

Boot → Menu → Sandbox → CompleteActivationWindow → ActivityRunning.
