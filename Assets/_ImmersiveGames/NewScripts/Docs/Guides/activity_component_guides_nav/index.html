Regra principal

Interface sozinha não integra nada.
O objeto primeiro precisa ser encontrado pela Activity. Depois disso, a interface ou contribuição diz em qual fase ele participa.
Objeto encontrado pela Activity -> componente declara o que sabe fazer -> pipeline/stage decide quando usar -> adapter chama -> componente executa a ação local

Duas formas de um componente entrar no sistema

Com Actor

Use quando o comportamento pertence a um Actor

Actor / PlayerActor ├── ActorCapabilitySurface └── SeuComponente

O Actor é encontrado pelo scan. O ActorCapabilitySurface funciona como o painel local onde os endpoints ficam visíveis.

Sem Actor

Use quando é objeto da Activity/cena

Objeto da cena ├── ActivityObject / Contributor / Marker └── SeuComponente

O objeto precisa ser marcado como participante/contributor da Activity. Sem isso, a Activity não sabe que ele existe.

Checklist rápido

  1. O componente está em um Actor ou em um objeto marcado da Activity?
  2. Se está em Actor, existe ActorCapabilitySurface?
  3. Se não é Actor, o objeto entra no scan como Activity Object/Contributor/Marker?
  4. O componente implementa a interface/contribution da fase correta?
  5. O componente não chama pipeline, save ou service global diretamente?
